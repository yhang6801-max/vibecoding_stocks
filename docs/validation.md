## 运行测试

在仓库根目录、已安装依赖的环境中执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

8 项测试另包含两份示例的全部事件点位核对；非法 CSV 用例覆盖重复日期、日期倒序、非有限价格和零价格。测试只验证输入契约，不渲染媒体。完整工作流见[快速开始](quickstart.md)，CPU 预览可使用：

```powershell
.\.venv\Scripts\python.exe tools/stock_video.py preview --project examples/kospi/project.json --seconds 2 --encoder libx264 --output output/kospi_cpu
.\.venv\Scripts\python.exe tools/stock_video.py preview --project examples/nikkei/project.json --start 29.6 --seconds 2 --encoder libx264 --output output/nikkei_cpu
```

制作命令会生成 `build_record.json`、`verification.json` 和 `review.html`，并从实际编码后视频解码审阅图片。输出文件不随源码仓库提交；重新执行后以本次输出记录为准。
