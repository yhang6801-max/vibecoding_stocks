# 两次制作留下的经验

这份复盘区分旧日股长片、日股新版静帧与韩股电影感长片。它们并非同一工程的不同名称。

## 日股：先让完整历史和节奏成立

原日股工程覆盖 1985-01-04—2025-10-31，10,021 条收盘数据。完整片为 1080×1920、30 fps、220 秒：3 秒开场、195 秒移动、17 个事件合计停留 20 秒、2 秒全景结尾。

- 开头预览曾只推进到局部历史，但标题覆盖 40 年。预览必须明确是局部片段，不能当完整版发布。
- 事件日期、名称、点位和验收范围散落在不同脚本中，单换 CSV 会残留旧标的。公开版将项目输入统一到配置与 CSV。
- 旧全景曾使用稀疏锚点，容易遗漏 2009-03-10 的 7,054.98 最低收盘。主图和长期小图都必须保留全量日线的极值。
- 1989 年旧高 38,915.87，与 2024-02-22 的 39,098.68 只差 0.47%。用数值与光效强调突破，不能抬高曲线端点制造幅度。
- 旧体验成片有音轨，但缺少音源、授权和混音工程。公开示例保留可复现的静音片，不把成片中存在声音等同于声音链路可复现。

后来确认的横屏“清晰讲述”和“电影感”日经静帧，是新视觉方向；它们不能证明旧竖屏工程具备相同动画和音效。

## 韩股：把电影感变成完整制作链

韩股工程覆盖 1990-01-04—2026-10-16，9,489 条日收盘，1920×1080、30 fps、120 秒。金白曲线、固定透视、低亮红青光幕、动态粒子与平面文字共同构成画面；无旁白，原创数学合成音乐与音效贯穿全片。

- **运动与真实报价分开。** 光点沿相邻真实收盘之间连续行进，报价面板和事件节点仍对应真实交易日；动画位置不写回成新行情。
- **只在必要处换视窗和纵轴。** 早期采用较长历史视窗，后段收窄，片尾再展开全历史。坐标与标签同用当前状态，避免曲线、光幕和刻度各自跳变。
- **分段仍用统一全局时间。** 多进程的每段使用相同随机种子、时间与运动函数；分段连接点采连续帧检查，不能只看单张抽帧。
- **高点不是终点。** 全期高点在 2026-06-22，最终日在 2026-10-16。封面与片尾保留高点后的回落，不能截到高点就结束。
- **配乐源码属于交付。** 保存乐器合成、编排、事件 cue、分轨生成与响度处理代码，声音跟随同一张事件表。技术验收包含全时长解码、响度、峰值与首尾；主观听感另记。
- **数据核验写清覆盖范围。** 7,924 条共同记录交叉核对，1,565 条为单来源，不把部分核验写成全部核验。
- **审阅图从最终 MP4 解码。** 渲染前截图可审核布局，最终编码帧才证明交付成片的画面；审阅页面应绑定当前视频和配置。

## 合并后的工作顺序

1. 确认受众、画幅、预设、指标口径与截止日，保留数据来源。
2. 逐条审核事件，用实际交易日从 CSV 获取价格；建立统一时间表。
3. 先核对开场、极值、长标签、镜头变化与片尾静帧，再跑短片。
4. 冻结配置后制作全片、配乐和封面；并行渲染保留连续性检查。
5. 技术验收后完整观看、试听，保存问题与修订记录。
6. 分别交付可编辑工程、发布文案、横竖封面和成片；模板仓库只保留可复现输入与工具。

本仓库的图库 SVG 是依据真实 CSV 重绘的静态示意，不作为上述视频验收证据。以上完整视频经验来自原工程；通用工具的复现状态见[视觉规范与验证状态](visual-spec.md)，实际通过项另行记录，不能直接继承原工程结论。
