# 常见问题

### 没有 NVIDIA 显卡可以制作吗？

可以。用 `--encoder libx264` 强制 CPU。`auto` 会实际检测 NVENC，再选择可用编码器；显卡型号或 FFmpeg 支持列表本身不能证明本机能编码。CPU 完整渲染可能较慢，先做 5 秒预览。

### 找不到 FFmpeg？

将其加入 PATH，或设置 `FFMPEG_BIN` 指向 `ffmpeg.exe`。环境检查、预览、制作和验收命令也接受 `--ffmpeg` 显式路径。封面仅需现有 Windows 绘图环境，无需 FFmpeg。媒体信息由同包的 FFprobe 输出 JSON；FFmpeg 负责完整解码检查。

### 中文乱码、缺字或字体找不到？

确认使用 PowerShell 7、UTF-8 的 JSON 与 CSV，Windows 已安装微软雅黑、Bahnschrift。Windows 后端依赖 `System.Drawing`；Mac 使用 SkiaSharp，安装与字体配置见 [Mac 指南](mac.md)。Linux 暂未验收。仓库不分发字体。

### 初始化后为什么仍是韩股／日股？

`init` 有意复制一套可跑的真实示例。换标的时按[新项目指南](new-project.md)同时修改数据、名称、事件、字幕、比较基准、来源和封面文案。不要只替换 CSV 或只改标题。

### 为什么事件价格与手填值不同？

价格以 CSV 对应交易日为准，无需手填。事件日必须是已有真实交易日；新闻发生在休市日时，另外记录事实日期，再选择图上实际交易日。不要补造报价。

### 为什么验收报告通过，图上标签仍可能不好看？

技术验收检查数据与媒体事实，不判断叙事节奏、长标签排版和主观听感。需要看关键帧、镜头过渡及完整播放。高点之后的回落、最后一个事件、片尾和声音首尾都应人工审阅。

### 可以改成一分钟、方形或任意音乐吗？

首版提供固定 120 秒横屏与 220 秒竖屏预设，封面另有 4:3 和 3:4。新时长或新画幅涉及重新排时间槽、镜头、字幕与配乐，需要重新开发和验收。外部音乐需自行保存音源与使用条件；日股示例默认静音。

### 图库的图片为什么和视频不是同一构图？

README 的 SVG 根据完整真实 CSV 自行重绘，用于快速展示数据和版式，不是编码后视频抽帧。视频使用移动视窗与不同时间状态；实际成片以本地审阅页面与最终 MP4 解码帧为准。

### 为什么仓库没有 MP4、WAV、所有渲染缓存？

源码、输入、配置和生成方法足以重新制作；缓存和媒体体积大且容易过时，默认不提交。未确定来源的旧日股体验配乐与他人的调研录屏也不分发。

### 数据会自动更新到今天吗？

不会。示例是有明确截止日的离线快照。新一期使用自己的真实 CSV 和来源记录，重新核对事件与文案。第三方行情的适用条件见[来源说明](../THIRD_PARTY_NOTICES.md)，不是 MIT 授权的一部分。
