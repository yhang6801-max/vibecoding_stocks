# 交给 AI 的新项目提示词

先运行 `init` 复制预设，将下面的 `{{…}}` 替换为本期信息。提供真实 CSV 与可访问的来源，不让 AI 凭记忆编造历史价格。此提示词用于在本仓库中制作新一期，不要求更换技术栈。

```text
请在 vibecoding_stocks 仓库的现有工具上制作一期历史走势视频。

目标：{{标的中文名、代码、交易所}}，受众与平台：{{描述}}。
使用已复制的项目：{{project.json路径}}。
预设：{{cinematic120：120秒1920×1080有配乐 / classic220：220秒1080×1920静音}}。
数据：{{真实CSV路径}}，来源与获取日期：{{URL和日期}}。
指标口径：{{价格指数 / 总回报指数 / 复权收盘价}}，单位：{{点或货币}}。
开始与截止：{{日期区间}}。叙事主线：{{起点、转折、终点}}。
已核实的背景与事件来源：{{事实、日期、URL列表}}。

先阅读 AGENTS.md、README、docs/new-project.md、docs/visual-spec.md、templates/production-template.md 和所选示例配置。沿用现有 Python、共享 C# 渲染器和 FFmpeg 制作链；Mac 使用 SkiaSharp，Windows 可使用 PowerShell/System.Drawing，不随意重写渲染器。

请先检查 CSV 的 date,close、真实交易日、正数、升序和重复日期，列出首尾、样本数、区间最低最高、长缺口及待核问题。不要造价、补造交易日、用少量锚点代替日线，或移动端点制造突破。

修改项目配置，使标的名、代码、单位、数据路径、来源、显示范围、事件、章节、字幕、历史背景、比较基准、关口与发布文案全部属于本期。事件填写实际交易日和短标签，价格由 CSV 获取。休市日新闻另外记录事实日。所有配置相对路径以 project.json 所在目录解析。

保留所选预设的画布、帧率、时长与事件到达/停留时间槽；用本期实际事件日期与文字替换。电影感预设保留E01—E04分镜节点ID，首尾事件分别对应CSV首尾，首事件arrival为0；日股事件在218秒前结束。阶段颜色沿用预设的明确口径，不能解释为成交量。字幕中具体价格和百分比根据本期数据重新计算。无法证明的“首次”“导致”“熔断”等词标为待核，不直接写进成片。

使用 python tools/stock_video.py 的 doctor、preview、build、covers、verify 命令。先做5秒CPU预览和关键布局检查，再制作全片。电影感片沿用原创配乐源码，并使音频提示点与同一事件表对齐；日股旧版默认静音，不借用缺少授权和源文件的旧体验音轨。

封面分别生成1440×1080的4:3横版、1080×1440的3:4竖版，独立排版、留7%文字边距，完整历史保留高点后的回落。发布标题不超过30字，简介含话题不超过1000字，写清截止日与指标口径。

核对数据、首尾、事件、极值、最后高点后的走势、镜头过渡与分段衔接；验收尺寸、帧率、帧数、时长、完整解码和音轨。声音检查全程覆盖、响度、峰值、首尾，并将实际试听与技术检查分开记录。新标的不得残留旧标的文字、日期和来源。

交付本地成片、短预览、横竖封面、可复制文案、配置、CSV、来源记录、可重做的配乐源码和验收结果。明确哪些项目已实际验证，哪些只做过静帧或技术检查；不要把计划写成已完成。若无法播放或试听，明确留下此项人工审阅，不伪称主观检查完成。
```

## 仅补充封面与发布文案

已有成片时使用下面的短提示，避免无意重制视频：

```text
依据已完成视频的 project.json、真实 daily.csv 与已核实的截止日，生成发布文案和独立横竖封面。
沿用 publishing 字段，必要时改短标题与副标题。标题不超过30字，简介含话题不超过1000字。写明数据区间、口径与是否含分红再投资。
运行现有 covers 命令，输出1440×1080（4:3）和1080×1440（3:4）PNG。主标题在25%缩图仍清楚，关键文字留7%边距。保留完整历史、区间极值与高点后的回落，注明截止日期。
检查尺寸、中文、遮挡、字数和文件大小，交付图片与可复制文案。不要改数据、不要上传发布页、不要将封面当作成片解码证据。
```
